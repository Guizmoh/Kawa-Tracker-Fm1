K-WA SUB

FM-1 bass synthesizer · emulator · v0.1
Écran actif. Le son démarre avec « Allumer le son ».

PAGES

  • HOME 01 PLAY · EDIT 02 BASS · ENV 03 ENVELOPE · SEQ 04 FILTER
  • LFO 05 LFO · FX 06 FX · ARP 07 PRESETS · GLO 08 SYSTEM
  • Le même bouton ou SEL : vue suivante (OSC A, OSC B, SUB, COMBINE…)
  • SELECT choisit la ligne, ALGO change sa valeur, K1–K4 font ce que dit le bas de l'écran
  • PRESETS charge le patch suivant, où que l'on soit

JOUER EN LIVE

  • Page PLAY : K1 cutoff, K2 vitesse du wobble (calée sur le tempo), K3 profondeur, K4 résonance
  • PLAY = HOLD : la note reste, les mains sont libres pour le wobble
  • REC = TAP tempo ; le LFO se recale sur la frappe
  • SAVE ouvre l'enregistrement (banque B), SAVE encore pour écrire
  • OCT- + OCT+ ensemble : tout couper

CLAVIER DE L'ORDINATEUR

  • Notes : ZSX… et Q2W…
  • ↑↓ ligne · ←→ valeur · PgUpPgDn preset
  • Shift+1…8 pages · Tab vue suivante · Espace HOLD · Entrée TAP
  • - = octave · molette ou glisser sur un bouton rotatif
